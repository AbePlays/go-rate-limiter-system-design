About this little project

A rate limiter built in Go — admission control with understood trade-offs, not magic middleware.

What's under the hood

  • Three algorithms: fixed window, sliding window counter, token bucket
  • Per-key rooms with a per-IP floor underneath — deny wins
  • Redis shared state via atomic Lua scripts, TTL-bounded keys
  • Fail-open by default, fail-closed where over-admit is unacceptable
  • Standard headers on every response, 429 + Retry-After on deny

Planned

  • Shortener redirect route limited live
  • Per-route env-driven policies

Tech stack

  • Go
  • Redis
  • Docker Compose
  • Plain HTML & CSS (no JavaScript)

Source

This project is open source. View it on GitHub.

Made for learning system design the hands-on way.
